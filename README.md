# 747-8F Tech Guide

Personal offline study guide for the Boeing 747-8F, built chapter by chapter from the AOM.

- The site at the root of this repo (`index.html`, `sw.js`, `manifest.webmanifest`, `icons/`) is what GitHub Pages serves.
- `source/` holds the app code and chapter content; `python3 source/build.py` rebuilds the site.

Study aid only, not approved data. The AOM and company procedures govern.
